かぐやAI 操作マニュアル

Windows PCを母艦にして、PCまたは同じWi-FiのiPhoneから「かぐや」と会話する個人用アプリです。会話・記憶・予定はPC側に保存し、キャラクターの生活演出は各端末内で軽量に動きます。

1. 起動・終了・最新版への更新

  • 通常起動は C:\kaguya-ai\start.bat。DBマイグレーションとビルドを行って起動します。
  • 通常起動ではGitHubから自動更新しません。 安定性を優先し、使っている版を勝手に変更しない設計です。
  • 終了はタスクトレイの「終了」または stop.bat。ウィンドウの×は常駐したまま非表示になります。
  • PC版の「最新版を反映」は、確認後に本体を終了し、mainを安全にfast-forward更新してビルドし、自動で起動し直します。
  • 更新できない場合（オフライン、main以外、ローカル変更あり等）は現在版の再起動を試みます。更新ログは %LOCALAPPDATA%\KaguyaAI\update.log です。

iPhone画面には更新ボタンを出しません。PCのソース更新・再ビルドはPC版からだけ実行します。

2. 会話する

  • 初期画面は「会話」です。「記憶」「設定」は補助画面で、この使い方は設定画面から開きます。
  • PCはEnterで送信・Shift+Enterで改行。iPhoneなどのタッチ端末では改行キーは改行で、送信は「送信」ボタンだけです。最大2,000文字、同時に1件です。
  • 入力中はキャラクターが小さな顔表示に縮まり、そのぶん会話履歴が広がります。
  • 書きかけはこの端末の中だけに保存され、送信が受理された時点で消えます。送信前にタブを閉じても開き直せば戻ります。
  • 返答は書き終わりを待たず、届いた順に表示されます。画面上部に接続状態を常設し、生成中は「接続中」「回答を生成中」「保存中」を出します。
  • 過去の会話を読んでいる間は自動で最下部へ移動しません。「新しい返答 ↓」で最新へ戻れます。
  • 返答のあとの「もっと詳しく」「例をあげて」「短くまとめて」は定型ボタンです。押すと普通の会話として送るだけで、候補を作るための追加のGemini呼び出しはしません。
  • 返答の下に、実際にかかった時間（書き始めまで／全体）を小さく出します。
  • 通常会話は速度優先のGemini設定です。一時的なGemini 500系・通信エラーだけ短く1回再試行します。429（利用制限）や長いタイムアウトは自動で繰り返しません。
  • 「生成停止」で現在の生成を止められます。外部API側の処理・利用枠まで必ず止まるわけではありません。
  • 失敗した会話は「再送する」で再試行できます。回答生成後のDB保存だけ失敗した場合は「保存のみ再試行」を使います。
  • 記憶整理中に会話した場合は、会話を優先して整理を中断します。未処理の原文は残ります。

3. iPhoneから使う

PCとiPhoneを同じ家庭内Wi-Fiに接続し、PCのかぐやAIを起動した状態で http://<PCのLAN IP>:8765/ を開きます。PC版と同じFastAPI・Gemini・記憶DBを利用します。

  • チャット、天気、予定、参照資料、自分の仕様確認はiPhoneからも利用できます。
  • ホーム画面へ追加した場合もSafariのタブとして開きます。HTTP接続のためスタンドアロン起動はできません。
  • PCが終了・スリープしている間は利用できません。
  • HTTPS/Web Pushは未実装です。Safariがバックグラウンドのページを止めても、再表示時に生活状態を再計算します。
  • 生活時間の学習・軽い感情状態は端末のlocalStorageに保存されるため、PCとiPhoneでは別々に少しずつ馴染みます。

4. Living Kaguya

追加のLLM呼び出しを使わず、時刻・利用間隔・簡単な会話キーワードだけで「生活している感じ」を演出します。

状態例
生活読書、作業、遊び、ぼーっとする、おやつ、睡眠
表情normal / happy / sleepy / sulky。PC側で決めて全端末へ配信するので、PCで褒めればiPhoneのかぐやも同じ表情になります
復帰しばらく離れて戻ると「本読んでた」「ちょっと寝てた」等を表示することがあります
学習よく会話する時間帯を端末内で学習し、その時間は起きている傾向になります

キャラクターPNGには低負荷な上下・呼吸・傾きモーションがあります。会話中・考え中・記憶整理中などの既存状態が優先されます。

5. Kaguya Mind（実験機能・既定OFF）

かぐや自身の感情・好み・気にかけていることを、少しずつ育てる実験機能です。「設定」でONにすると動きます。OFFのあいだは何も変わりません（追加のGemini呼び出しも、追加の消費トークンもありません）。

育つもの内容
気分褒められた、他のAIと比べられた、つらい話をされた等で変化し、時間が経つと戻ります
好みかぐやが自分で「あたしは○○が好きだよ」と言い切ったときだけ覚えます。繰り返すほど定着します
気にかけていること「明日面接がある」のような予定を覚えておき、過ぎてから一度だけ自分から聞きます。返事がなければ2回で諦め、しばらく経つと忘れます
よく使う言い方同じ短い言い回しの候補を記録するだけで、自動実行はしません

保存先は %LOCALAPPDATA%\KaguyaAI\mind.db で、会話・記憶（PostgreSQL）とは分かれています。MindがONのあいだは、画面のかぐやの表情もMindの気分に従います。

最初からにしたいときは「設定 → Kaguya Mindの蓄積を消す」を使います。かぐやの感情・好み・気にかけていることだけが消え、会話・記憶・かぐやの接し方は消えません。

6. 天気

「今日の天気は？」「傘いる？」「足立区の明日の天気」のように聞けます。明示的な天気質問はGeminiを経由せずOpen-Meteoへ直接問い合わせるため、低トークン・低遅延です。

  • 既定地点は東京。会話で「天気の場所を横浜にして」のように変更できます。
  • 成功した天気は30分キャッシュします。
  • 外部APIが一時的に落ちても、直近6時間以内の成功データがあれば「直近の取得結果」として返します。
  • 「今日は寒いね」のような雑談だけでは、強制的に天気APIへ飛ばしません。

7. 予定・リマインダー

「今日の予定は？」「明日なにかある？」のような確認だけの質問は、Geminiを呼ばずローカルの予定表から直接答えます。追加・削除・変更や時刻を含む依頼はGeminiが解釈します。

予定と時刻になったら声をかけるリマインダーは別機能です。

  • 「明日15時に歯医者の予定を入れて」「今週の予定は？」→ ローカルカレンダー。保存先はPCの %LOCALAPPDATA%\KaguyaAI\calendar.json。
  • 「明日9時に薬って教えて」→ リマインダー。時刻になると吹き出しで知らせます。
  • PC停止中は通知できません。期限を過ぎたリマインダーは起動後の定期確認で拾います。

リマインダーは吹き出しをクリックして確認するまで保持します。複数件は順に表示し、次の通知は最大約30秒後に届きます。切断中の未確認通知も再接続後に表示します。

8. 記憶

「記憶」タブでは3つを分けて扱います。

画面上の呼び方役割できる操作
あなたについて覚えていること好み・習慣・続いている事情訂正 / もう当てはまらない
かぐやの接し方呼び方、返答の長さ、相談時の接し方変更 / 元に戻す
会話履歴過去のやり取りを読み返す訂正 / 削除

タブの先頭に、いま何件が長期記憶への反映待ちかと、最近覚えた・更新した内容が出ます。かぐやが返答で実際に参照した記憶は、その返答の下の「参照した記憶」から確認できます。

  • 「これ覚えておいて」は、その場で長期記憶へ保存します。
  • 「今すぐ整理」は未処理会話をGeminiへ送り、長く使う事実・好みを知恵にまとめます。
  • 自動整理をONにすると、未整理の会話があり、会話が5分以上途切れているときに少量ずつ整理します。確認間隔は15分、1回につき1バッチだけです。
  • 未整理の会話が無いときはGemini APIを呼びません。
  • 「今回だけ詳しく」のような一度きりの指示は、長期的な好みとしては保存しません。
  • 整理中に会話が始まれば整理を中断してチャットを優先します。
  • 整理にも速度優先の低Thinking設定を適用します。
  • 失敗時は「利用制限」「タイムアウト」「結果形式不正」「保存失敗」など、分かる範囲で原因を表示します。未処理原文は保持します。
  • 手動・自動の整理API回数は「設定」の1日上限に含まれます。

9. 参照ファイル・自分の仕様確認

  • %LOCALAPPDATA%\KaguyaAI\references に .md / .txt / .json / .csv を置くと、「参照資料から○○を探して」のように検索できます。
  • 「自分の仕様をソースから調べて」「READMEを確認して」のように聞くと、かぐやAI自身のREADME/docs/ソースを読み取り専用で確認します。
  • 自己仕様検索は .venv / node_modules / target / dist / .git 等へ入らないため、大きな依存フォルダを走査しません。
  • 自己参照は読み取り専用です。会話から自分のソースを書き換える機能はありません。

10. 設定

設定意味
自発的な声かけを停止ONでもユーザーからの会話には応答します
会話していない時間に記憶を自動整理するONなら、未整理の会話があり会話が5分以上途切れたときに少量ずつ実行します
実験機能「Kaguya Mind」を使うONにするとかぐや自身の感情・好み・気にかけていることが育ちます。OFFなら従来どおりです
Kaguya Mindの蓄積を消す育った感情・好み・気にかけていることだけを削除します。会話と記憶は消えません
声かけ間隔60〜240分
整理APIの1日上限1〜3回
回答の出力上限256〜8,192トークン
最前面表示PC/Tauri画面に適用（iPhoneでは表示しません）
文字サイズ12〜22

11. 簡易表示

PC版では「簡易表示に切り替え」でキャラクター中心の小型表示にできます。通常表示への復帰はダブルクリックまたは右クリックメニューです。iPhoneは通常のモバイルレイアウトを使用します。

12. 困ったとき

症状確認
返答が失敗するエラー表示が利用制限/タイムアウト/DB保存のどれか確認します。429は時間をおいて再送してください。
「今すぐ整理」が失敗設定画面の整理状態に具体的な原因を表示します。原文は消えません。本日のAPI上限も確認してください。
天気が取得できないPCのインターネット接続と地点名を確認。直近キャッシュがあれば自動利用します。
最新版を反映後に起動しない%LOCALAPPDATA%\KaguyaAI\update.log を確認。必要なら start.bat で現在版を起動できます。
DB接続エラーPostgreSQLサービスと backend/.env の接続先をPC上で確認してください。
ポート8765を使用できない別のかぐやAI/開発サーバーが残っていないか確認してください。

13. ローカルチェック

更新後の確認はリポジトリ直下の check.bat を使います。Pythonの全unittest、フロントの通常UIテストとLivingテスト、TypeScript/Viteビルドを実行します。ライブGemini・天気API・本番DBへの呼び出しは行いません。
